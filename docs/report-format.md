# 罗盘收支分析：字段与汇总规则

这是导入程序的格式说明，只保存表头和规则，不保存真实报表、账号或经营金额。

## 已确认的结构

- 标准 `.xlsx` 文件，第一行是单行表头，无需合并表头识别。
- 必须包含“收支分析”“账号收支详情”两个工作表。
- 每张已识别工作表有 4 个维度字段、26 个金额字段和 13 个比率/效率字段，共 43 个必需字段；允许字段换序。
- 新增字段保留展示，尚不校验其业务含义。额外工作表原样展示，不参与金额核对；空工作表显示零条记录。
- 隐藏工作表也会读取并计入工作表数量；不是只看 Excel 当前打开的一张表。
- 记录数不含表头和全空行，包含汇总行和细分行。界面显示原文件行号，分页不改变总记录数。

## 日期和数据粒度

“收支分析”的唯一粒度是：日期 × 经营类型 × 载体类型 × 推广时段。

| 字段 | 已支持值 |
| --- | --- |
| 日期 | YYYYMMDD、YYYY-MM-DD、YYYY/M/D，或 Excel 日期单元格 |
| 经营类型 | 全店、自营、合作 |
| 载体类型 | 全部、直播、短视频、商品卡、图文、其他 |
| 推广时段 | 不限、全域+乘方投放时段、标准+品牌投放、非投放时段 |

完整的一天可同时有 3 × 6 × 4 = 72 种组合。其中“全店”“全部”“不限”分别是各自维度的汇总值，存在维度包含关系；它们不是 72 份独立收入。

“账号收支详情”的唯一粒度是：日期 × 账号名称 × 账号类型 × 抖音号。它不是逐笔订单或逐场直播明细，不与全店表相加。账号名称、账号类型、抖音号不能为空；账号标识只作为文本展示。

日期必须为真实日历日期，在 2000 年起且不晚于浏览器本地日期。日期异常阻止导入；日期不连续或两表日期覆盖不一致时给出提示，不补零。文件名日期仅辅助提示，界面范围来自记录中的日期。

13. 成交退款金额（支付时间）
14. 退款金额（支付时间）
15. 智能优惠券退款（支付时间）
16. 平台补贴退款（支付时间）
17. 达人补贴退款（支付时间）
18. 成交退款金额（退款时间）

金额支持数字单元格和数字文本，最多两位小数，支持负数。空值、`-`、货币符号、千分位文本、公式或非数字文本会阻止导入并提示工作表、原文件行号和字段。不会将无法读取的金额偷偷转换成零。当前“免佣金额明细”按此类报表实际提供的数值字段处理，不支持嵌套明细文本。

## 比率和效率字段（13 个）

1. 投放费比（店铺被投）
2. 投放费比（剔除退款、店铺被投）
3. 投放费比（店铺绑定）
4. 投放费比（剔除退款、店铺绑定）
5. 综合费比（店铺被投）
6. 综合费比（剔除退款、店铺被投）
7. 综合费比（店铺绑定）
8. 综合费比（剔除退款、店铺绑定）
9. 投放效率（店铺被投）
10. 投放效率（店铺绑定）
11. 全店效率（店铺被投）
12. 全店效率（店铺绑定）
13. 退款率（支付时间）

这些字段接受有限数值和 `-`。`-` 表示未提供值，原样展示，不视为零。保留 Excel 中的数值表示，不自动改成百分数；不直接求和，不简单平均，也不猜测平台分子、分母口径。

## 正确的金额核对方式

- 全店核对只筛选“全店＋全部＋不限”，每个日期只能一条，然后跨日期加总同一个金额字段。
- 程序仅展示该口径的成交金额、结算金额、支出金额作为导入核对，使用整数“分”计算，避免小数累计误差。这些核对不是经营总览或利润分析。
- 必须保留负数结算金额；退款发生日期与原支付日期不同，不代表金额格式错误。
- 不把汇总行与它的细分行叠加，也不把两个工作表叠加。不要把已包含关系的金额字段再相加。
- 上传样本中，成交金额、结算金额和支出金额在各维度的汇总值均与互斥细分项之和一致，已逐组核验；不能因此把汇总值与细分项同时纳入求和。
- 分析自营或合作、某载体或某推广时段时，应固定其他维度的口径，仅选择目标层级；不能再次加入全店、全部或不限。是否可用细分项重建总额，还需核验平台分类覆盖与排他性，本版直接使用已提供的汇总行。
- “7日结算金额”“14日结算金额”与“结算金额”分别保留，不把它们相加成“总收入”；支付时间和退款时间两种口径也分别保留。
- 重复日期与维度组合会阻止导入，避免把重复记录当成独立收入。

## 可用指标与缺少的字段

当前数据允许核对一致维度下的成交、结算、退款、投放消耗、补贴及佣金等原表金额。平台比率可按原值查看，但跨日比率需要先确认平台公式与原始分子、分母，本版不计算。

以下内容不能凭此文件可靠计算：

| 想计算的指标 | 缺少或未确认的字段 |
| --- | --- |
| 成交订单数、客单价 | 订单数或订单明细 |
| 观看人数、观看成交转化率 | 观看人数、去重口径、相关订单数 |
| 直播场次、场均或小时表现 | 场次标识、开播/下播时间、时长 |
| 单品表现 | 商品标识、商品级记录 |
| 净利润 | 商品成本、物流及其他完整成本、税费等 |
| 跨日平台退款率/效率 | 平台明确公式与对应口径的分子、分母 |

经营总览已按本文粒度读取可用金额及比值；缺少人数或广告归因依据的指标显示无法计算。详细定义见 [经营总览指标](overview-metrics.md)。直播复盘仍待开发。
