# 经营总览：指标、筛选与限制

本模块只使用 `app.js` 已成功校验的同一份导入结果（`currentReport`），通过 `OverviewUI.setReport()` 更新。不另行读取文件，不合并历史文件，不调用平台或 AI。`overview.js` 只负责纯计算，`overview-ui.js` 负责展示。

## 数据来源与汇总层级

### 店铺维度

来源工作表：**收支分析**。唯一粒度：日期 × 经营类型 × 载体类型 × 推广时段。

- 默认筛选：经营类型=全店、载体类型=全部、推广时段=不限。
- 每日只选择这个组合的一条记录，然后跨日期加总。不要把“全店”再加上自营/合作，也不要把“全部”再加上直播等细分。
- 经营类型、载体、推广时段选项均从真实导入记录中生成，不制作不存在的选项。
- 每项来源说明列出工作表、字段、日期、筛选和汇总规则。每日明细标出原文件行号。

### 单个账号

来源工作表：**账号收支详情**。用户必须选择一个实际存在的抖音号，不制作多个账号相加后的“全店”。

- 同一天同账号只允许一条记录参与计算，避免账号名称或类型变化导致重复累计。
- 此表没有经营载体、推广时段等维度，因此切换到账号视图后禁用这些筛选，明确提示它们不适用。
- 账号视图不使用全店数据回填；直播成交金额无法按载体拆出，因此显示“无法计算”。
- 账号成交范围不等于全店范围，不能把两个工作表相加。

## 指标定义

| 指标 | 使用字段 / 公式 | 重要限制 |
| --- | --- | --- |
| 成交金额 | 同范围 `成交金额` 跨日求和 | 不等于支付金额、结算金额或利润 |
| 直播成交金额 | 同日期、经营类型和推广时段下，`载体类型=直播` 的 `成交金额` 求和 | 当前载体为“全部”时读取其直播子集；当前载体为“直播”时等于当前成交金额。非直播载体和单账号视图显示无法计算，不混用范围 |
| 投放消耗 | `投放消耗（店铺被投）` 或 `投放消耗（店铺绑定）` 求和 | 用户选择一种口径，不将两者相加；标题和趋势同步显示具体口径 |
| 成交退款金额 | `成交退款金额（支付时间）` 或 `成交退款金额（退款时间）` 求和 | 两种时间口径不同，必须选择并明确显示 |
| 成交退款金额占比（支付时间） | 同范围支付时间口径成交退款金额 ÷ 成交金额 × 100% | 先汇总分子分母，不平均每天的退款率；选退款发生时间口径时不计算 |
| 整体成交消耗比 | 同范围成交金额 ÷ 所选投放消耗 | **包含自然成交，不等于广告归因投产比**，也不等于利润 |
| 支付转化率 | 同范围支付人数 ÷ 对应观看或访问人数 | 当前缺少人数、来源口径和区间去重依据，无法计算，不用订单数或人次替代 |
| 人均客单价 | 同范围支付金额 ÷ 区间去重支付人数 | 当前缺支付人数和区间去重依据，无法计算；支付金额÷支付订单数应叫订单均价，本报表也缺订单数 |
| 广告归因投产比 | 广告归因成交金额 ÷ 对应广告消耗 | 缺归因成交字段及消耗匹配关系，无法计算，不拿全店成交或原表“投放效率”冒充 |

即使未来增加逐日人数，也不能在缺少区间去重依据时直接跨日相加计算期间转化率或人均客单价。本版本不会根据新增字段名自动猜测业务口径。

## 数据更新时间与退款截至时间

- 顶部展示真实文件名、文件记录日期范围、**本地导入时间**。
- 当前报表没有可靠的平台数据更新时间或退款数据截至时间，明确显示“报表未提供，无法确认”。
- 工作簿创建/修改属性、文件修改时间、文件名末日、浏览器导入时间都不当作平台数据截至时间。
- 支付时间口径占比仅表示该次导出快照；后续退款可能改变结果，不称为最终退款率。
- 退款发生时间在所选期间，不表示原订单支付时间也在本期，因此不能除以本期成交额称为本期退款率。

## 缺失、零值与计算精度

- 金额沿用导入模块的严格校验：缺值不转为 0，错误文件拒绝替换。
- 对每个所选日历日检查匹配记录。**无记录**显示缺失；有记录且原金额为 0 才是真实零值。
- 只要某个指标有缺失日、重复日或无效字段，就不输出完整期间合计；卡片显示“无法计算”及原因。明细仍保留已知日期的真实值。
- 选到文件之外或当前维度没有记录时显示空筛选提示；日期倒置或无效会提示，不残留旧筛选结果。
- 分母为 0、负数、缺字段、范围不匹配时显示“无法计算”，不显示无穷大或将缺失当零。
- 金额全程使用 BigInt 整数“分”；比率用整数缩放并四舍五入到两位，先汇总再求比，不使用 JavaScript 浮点加总金额。
- 只有 SVG 图形坐标使用近似数字；精确金额以卡片、提示点和每日明细为准。
- 趋势图的缺失日断线，有真实零值的日期画在零线；每个点可用鼠标悬停或键盘聚焦查看日期和金额。
- 明细每页 31 个日历日，图表覆盖整个所选期间，不只画当前明细页。
- 不展示无可比期间依据的同比、环比。金额、结算额、退款后成交额和消耗比均不能当作利润。

## 规则式经营提示

不接入 AI、不制作完整复盘系统。每条提示包含数据事实、待核实的问题、建议动作、后续验证指标。

- 支付时间口径存在退款时提示补充订单、退款原因、商品、场次明细。占比达到 50% 时注明这是本页排查提示线，不是行业标准；不直接判定主播、质量或履约问题。
- 有有效直播记录且成交为 0 时，提示先核实停播、数据缺失或统计范围变化，不判定直播效果下降。
- 有成交而所选消耗为 0 时，提示核对自然成交、账户归属和消耗口径，不把成交消耗比写成无限大。
- 缺日期时提示核对导出范围，不填零；退款时间口径时提示关联原支付批次。
- 没触发规则不代表经营正常或不存在风险。

## 导入生命周期

每次有效替换会重置日期和维度为新文件默认范围，重新生成卡片、趋势、明细、来源说明与提示。不会保留旧账号选项或旧日期数据。

重复文件跳过；取消替换或校验失败时，当前文件、时间、筛选和总览结果保持不变。刷新页面清空报表与总览，只保留静态空状态；不上传、不持久化经营数据。
